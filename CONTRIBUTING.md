# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a meaningful message.
5. Submit a pull request explaining your contribution.

## Reporting Bugs

If you find a bug, please open a GitHub Issue describing the problem and the steps to reproduce it.

## Documentation Improvements

Contributions that improve the README, documentation, or code comments are encouraged.

## Code of Conduct

All contributors are expected to follow the guidelines in CODE_OF_CONDUCT.md.

Thank you for contributing!
